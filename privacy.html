Privacy Policy for rclone

This private rclone configuration accesses the owner's Google Drive to synchronize files from the owner's Windows computer.

It processes file contents, names, folder structure and metadata. It can read, create, update and delete Google Drive files as required for one-way synchronization.

OAuth credentials and access tokens are stored in the local rclone configuration. Local logs may contain file names and errors.

File data is transferred between the owner's computer and Google Drive. This website does not receive files or OAuth tokens.

Google user data is not sold, used for advertising, or used to train AI models.

The owner can stop synchronization, revoke access through Google Account permissions and remove local credentials and logs. Cloud files can be deleted through Google Drive.

This configuration is intended solely for its owner.
